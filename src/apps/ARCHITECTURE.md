Mermaid diagrams for everything under [`src/apps`](.) and the application ecosystem. View in GitHub, VS Code (Mermaid preview), or [mermaid.live](https://mermaid.live).

## 1. Applications, Tooling, and Packaging (`src/apps` & `installer/`)

```mermaid
flowchart TB

    end

    subgraph manager ["Widget Management & Packaging"]
      Nwm["nwm/<br/>nwm.exe CLI"]
      Manage["manage_novadesk/<br/>manage_novadesk.exe GUI"]

    end

    subgraph install ["Installation & Setup"]
      Nsis["installer/setup.nsi<br/>NSIS Full Platform Installer"]
      Stub["installer_stub/<br/>installer_stub.exe SFX Bootstrap"]
    end

    Assets["assets/images/<br/>Shared UI Assets & Icons"]
  end

  Dev["Developer"] -->|"init / run / build"| Nwm
  User["End User"] -->|"manage widgets"| Manage
  User -->|"launch & interact"| NovadeskExe
  User -->|"double-click .ndpkg"| Ndpkg

  Nwm -->|"init / run / build"| WidgetSrc["Widget project<br/>index.js + meta.json"]
  Nwm -->|"packages .ndpkg"| Ndpkg
  Nwm -->|"embeds payload into"| Stub
  Stub -->|"self-extract install"| WidgetsDir["%DOCUMENTS%/Novadesk/Widgets/"]
  Ndpkg -->|"installs package to"| WidgetsDir
  Nsis -->|"installs Novadesk runtime to"| ProgramFiles["%ProgramFiles%/Novadesk/"]
  ProgramFiles --> NovadeskExe
  ProgramFiles --> Manage
  WidgetsDir -->|"loaded by"| NovadeskExe
  Manage -->|"loads / unloads widgets"| NovadeskExe
```

| Path | Role |
|------|------|
| [`novadesk/`](novadesk/) | Core widget runtime: layered windows, Direct2D UI, QuickJS scripting engine |
| [`nwm/`](nwm/) | CLI developer tool: `init`, `run`, `build`, `--install`; builds `.ndpkg` packages and standalone setup EXEs |
| [`manage_novadesk/`](manage_novadesk/) | GUI widget manager: list, load, configure, and monitor active widgets with tray integration |
| [`ndpkg_installer/`](ndpkg_installer/) | Lightweight GUI package installer for `.ndpkg` widget bundles |
| [`installer_stub/`](installer_stub/) | Self-extracting bootstrap EXE stub; payload appended by `nwm build` |
| [`assets/`](assets/) | Shared images, logos, and UI icons for manager and installers |
| [`../../installer/`](../../installer/) | Production NSIS installer (`setup.nsi`) with UAC elevation, per-user docs & AppData setup |

> Build output under `src/apps/x64/` is generated by MSVC projects and is not part of the source layout.

## 3. `novadesk/render/` — Element and Shape Tree

```mermaid
classDiagram
  class Element {
    +int x, y, width, height

    +Render(ID2D1DeviceContext)
    +HitTest(x, y) bool
    +SetSolidColor(color, alpha)
    +SetSolidGradient(GradientInfo)
    +DispatchEvent(event)
  }

  class ShapeElement {
    +float strokeWidth
    +D2D1_DASH_STYLE strokeStyle
    +COLORREF fillColor, strokeColor
    +GradientInfo fillGradient, strokeGradient
    +CreateGeometry(ID2D1Factory)
  }

  class ElementLayoutBox {
    +DisplayType displayType
    +FlexDirection direction
    +int gap, padding, margin
    +vector~BoxShadow~ shadows
```

## 4. Script → Screen Data Flow

```mermaid
sequenceDiagram
  autonumber
  participant JS as Widget JavaScript
  participant Engine as QuickJS / JSEngine
  participant UI as WidgetUiBindings
  participant Parser as PropertyParser
  participant W as Widget
  participant Flex as FlexLayoutEngine
  participant E as Element / Shape
  participant D2D as Direct2DHelper / GPU

  JS->>Engine: ui.addRectangle({ width: 200, height: 100, fillColor: "linear-gradient(90deg, #f00 0%, #00f 100%)" })
  Engine->>UI: JsAddRectangle native dispatch
  UI->>Parser: ParseRectangleOptions(optionsObj)
  Parser-->>UI: RectangleOptions (with parsed GradientInfo & CSS stops)
  UI->>W: AddShape(options)
  W->>E: Instantiate RectangleShape & apply properties
  W->>Flex: Recalculate container bounds (if in LayoutBox)
  Flex-->>W: Updated element layout coordinates
  W->>W: Invalidate / Trigger Redraw()
  Note over W,D2D: Direct2D BeginDraw on layered window DC
  W->>E: Render(ID2D1DeviceContext)
  E->>D2D: CreateGradientBrush(rect, GradientInfo)
  D2D-->>E: ID2D1LinearGradientBrush
  E->>D2D: FillRoundedRectangle / DrawGeometry
  W->>D2D: EndDraw & UpdateLayeredWindow
  D2D-->>JS: Rendered on Desktop
```

## 5. `nwm` CLI & Packaging Workflow

```mermaid
flowchart LR
  subgraph nwm_cli ["nwm.exe CLI"]
    Init["nwm init &lt;name&gt;"]
    Run["nwm run"]
    Build["nwm build"]
    Install["nwm --install"]
  end

  Init --> Template["Generate Widget Template<br/>(meta.json, index.js, assets)"]
  Run --> Launch["Locate and Launch novadesk.exe<br/>Passing widget directory"]
  Build --> Ndk["Package .ndpkg archive<br/>(Zipped widget bundle)"]
  Build --> Sfx["Build Standalone Setup EXE<br/>(installer_stub.exe + embedded payload)"]
  Install --> AutoSetup["Run generated setup EXE<br/>installs widget to user directory"]
```
